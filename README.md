# RUBSARB — Fan Website

เว็บไซต์แฟนไซต์ (Fan Website) ของช่อง **RUBSARB** สร้างขึ้นเพื่อวัตถุประสงค์ทางการศึกษาและพอร์ตโฟลิโอ (Portfolio) โดยไม่มีความเกี่ยวข้องหรือได้รับการรับรองจากทางช่อง RUBSARB แต่อย่างใด

## เกี่ยวกับโปรเจกต์

เว็บไซต์แบบหน้าเดียว (Single Page) ที่รวบรวมข้อมูลเกี่ยวกับช่อง RUBSARB ได้แก่ สมาชิกในทีม หมวดหมู่รายการ ช่องทางการรับชม สินค้า และช่องทางการติดต่องาน
